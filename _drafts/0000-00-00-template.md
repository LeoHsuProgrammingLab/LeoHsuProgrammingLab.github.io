## A heading for the first idea

Body text. Markdown works as you would expect: **bold**, *italic*,
[links](https://example.com), and `inline code`.

```python
# Fenced code blocks are syntax highlighted.
```

### Images

Use the figure include rather than raw `<img>` so you get responsive WebP and
click-to-zoom for free:

{% raw %}
{% include figure.html
   path="assets/img/gallery/CO/your-photo.jpg"
   class="img-fluid rounded z-depth-1"
   zoomable=true
   caption="Optional caption." %}
{% endraw %}

### Math

Inline math is $$e^{i\pi} + 1 = 0$$, and display math goes on its own lines.

### Citing a paper

Add the entry to `_bibliography/papers.bib`, then cite it by key with the
`cite` tag. See the bibliography example in `_al_folio_examples/_posts/`.
