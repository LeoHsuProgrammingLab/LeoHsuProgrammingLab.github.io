# al-folio example content

These are the demo posts that ship with the [al-folio](https://github.com/alshedivat/al-folio)
theme. They were moved out of `_posts/` so the blog shows real writing instead of
theme samples.

Jekyll ignores any top-level directory whose name starts with `_` unless it is a
declared collection, so nothing in here is built or published. It is kept as a
reference: the posts demonstrate images, code blocks, math, tables, diagrams,
videos, audio, citations, table of contents, custom blockquotes and Jupyter
notebooks.

To bring one back, move it into `_posts/` and give it a current date in the file
name.
